# ui-calling

The CLI for UI_calling: sets it up in your app, scaffolds screens, and prints the guide.

```bash
npx ui-calling init                     # Next.js, Vite or React Router: runtime, store, API routes, screen route
npx ui-calling new shift-picker         # contract, screen and server half, registered
npx ui-calling add link-account         # a ready-made block (npx ui-calling list)
npx ui-calling link shift-picker id=1   # open it for a test user on your dev server
npx ui-calling guide                    # the guide; guide toc for its sections and the recipes
```

The code it writes is yours to change, like shadcn/ui.
